# Data-Analysis-Mini-ProjectProject Overview and Objective:
The Hospital Data Analysis project aims to analyse patient records to identify healthcare trends, treatment outcomes, hospital costs, and patient satisfaction. The project transforms raw hospital data into meaningful insights using Microsoft Excel for data preprocessing and Microsoft Power BI for interactive dashboards and business intelligence reporting. 
Objectives
•	Analyse patient demographics. 
•	Evaluate treatment costs across different medical conditions. 
•	Monitor average hospital stay. 
•	Identify patient readmission total. 
•	Measure treatment outcomes. 
•	Analyse patient satisfaction levels. 
•	Build an interactive Power BI dashboard. 
•	Generate actionable insights for hospital management. 
Data Sources:
•	The data used in this project consists of two datasets: a raw dataset in CSV format and a cleaned dataset in Microsoft Excel format. The raw dataset contains the original patient records collected from a hospital information system
•	The cleaned dataset served as the primary source for analysis and dashboard development in Microsoft Power BI, ensuring that the visualizations were based on accurate and reliable data.
Problem Statement:
	Hospitals generate large volumes of patient data daily. Without proper analysis, valuable information related to treatment costs, patient outcomes, hospital stay, and satisfaction remains underutilized. The primary challenge is to transform raw patient records into meaningful business intelligence that supports hospital administrators in making informed decisions. This project addresses that challenge by cleaning, analysing, and visualizing hospital data to uncover trends and performance indicators.
